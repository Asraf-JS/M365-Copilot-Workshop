## How to use this book

This book collects everything from the two-day Microsoft 365 Copilot workshop in one place, so you can follow along offline and keep it at your desk afterwards.

Each chapter matches one topic of the workshop and has two parts:

- **Notes** explain the concepts and walk you through each feature step by step, with screenshots.
- **Hands-on exercises** give you copy-ready prompts, with where to run them, which grounding to use and which model to pick.

Look out for the coloured boxes. Blue boxes are notes and license differences, teal boxes are tips and good habits, purple boxes are things to try, and orange boxes are key points.

Prefer to copy prompts rather than retype them? Every prompt in this book is also online at **github.com/Asraf-JS/M365-Copilot-Workshop**, where each code block has a copy button.

## Workshop scenario

Throughout this workshop you work on one connected project from start to finish.

> **You are creating an AI Usage Guide for your department.** This guide will explain how your team should use AI tools responsibly and effectively.

Each chapter moves the project one step forward:

| Stage | What happens |
|-------|-------------|
| Research | Use Copilot Chat to research AI best practices, regulations, and department-specific use cases |
| Draft | Move your research into Copilot Pages and build the first draft of your guide |
| Refine | Open the draft in Word and reformat it as a formal management proposal |
| Submit | Email the proposal to your supervisor for approval using Copilot in Outlook |
| Present | Turn the approved document into a team presentation using Copilot in PowerPoint |
| Survey | Build a knowledge quiz and feedback survey using Copilot in Forms |
| Analyse | Use Copilot in Excel to analyse the quiz results and surface insights |
| Automate | Build a simple weekly check-in agent in Copilot Studio to keep the feedback loop running |
